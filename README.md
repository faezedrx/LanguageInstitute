# Language Institute Management System
# سیستم مدیریت آموزشگاه زبان

---

## 🇬🇧 English

A web-based management system for language institutes developed using PHP and MySQL.

The system provides separate panels for Teachers, Education Department, and Office Staff to simplify academic and administrative processes.

### Features

| Role | Capabilities |
|------|--------------|
| Teachers | Login, view evaluations, view dropout reports, change password, submit end-of-term financial forms, send emails to Education Department |
| Education Department | View analytical reports, monitor teacher evaluations and dropout statistics |
| Office Staff | Register and manage data, access analytical reports |

### Technologies

- PHP
- MySQL
- HTML / CSS / JavaScript
- PHPMailer

### Versions

| Version | Description |
|---------|-------------|
| V1 | Initial implementation |
| V2 | Enhanced version with finance, email communication, analytics, and user management |

> Note: This project is a web-based implementation of a language institute management system. As with any software project, there is room for further improvements in software architecture, security, performance, and additional features.
